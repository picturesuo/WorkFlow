# WorkFlow 0.5.1

WorkFlow can now protect active dictations from accidental Escape presses.

## Escape protection

Open **Settings → Shortcuts** and enable **Ignore Esc while recording**. While the switch is on:

- Escape does not cancel audio that is connecting or recording.
- Repeated Escape presses remain harmless.
- Use the configured recording shortcut to stop and transcribe normally.
- Escape behavior after recording, including the transcribing indicator, remains unchanged.

The existing **Cancel without confirmation** option is disabled while protection is active, and its previous value is preserved if protection is later turned off.

This release provides GitHub's source archives. Follow the [Quick Start](https://github.com/picturesuo/WorkFlow/blob/master/docs/QUICKSTART.md) to build and install the app. A public notarized app zip still requires Apple Developer ID and notarization credentials.
