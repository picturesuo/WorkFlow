# WorkFlow 0.4.0

WorkFlow is a private, local-first macOS dictation app with optional, literal AI cleanup. Hold Fn, speak, and release to insert the newest dictation at the active cursor.

## Highlights

- Fixes stale and duplicate pastes by allowing only the newest dictation to claim the paste operation.
- Improves short-utterance and Parakeet transcription behavior, including the FluidAudio 0.15.6 alignment fixes and explicit language hints.
- Adds hard provider deadlines so a slow cleanup request cannot leave dictation hanging indefinitely.
- Adds reusable API connections, a default $0.25 monthly Bedrock guardrail, and clear per-use cost estimates.
- Adds accessible labels and hints across settings, cleanup, personalization, and history.
- Adds a distinct WorkFlow visual identity, app icon, indicator, and color system.
- Adds user and agent setup guides that keep API secrets in the macOS Keychain.

## Install

This release provides GitHub's source archives. Follow [Quick Start](https://github.com/picturesuo/WorkFlow/blob/master/docs/QUICKSTART.md) to build and install `/Applications/WorkFlow.app`; the installer signs and verifies the local app before replacing an earlier build.

A notarized app zip is not attached yet because the repository is not configured with an Apple Developer ID certificate and notarization credentials. Do not bypass Gatekeeper. Once those credentials are configured, the included release workflow produces and publishes a signed, notarized zip.

## API cost

Local transcription is free. AI cleanup is optional. At the AWS Nova Micro US rates checked August 21, 2026—$0.035 per million input tokens and $0.14 per million output tokens—a typical 200-input-token, 40-output-token cleanup costs about $0.0000126. One hundred such cleanups per day is roughly $0.04 per month, excluding taxes and future AWS price changes.

WorkFlow defaults to a $0.25 monthly Bedrock budget guardrail for models whose prices it can verify. Confirm current pricing in your provider account.

See [Agent Setup](https://github.com/picturesuo/WorkFlow/blob/master/docs/AGENT_SETUP.md) when an AI coding agent is doing the setup. Users enter API credentials themselves; agents should never request, read, print, or commit them.
